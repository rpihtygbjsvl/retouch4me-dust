## Overview

Retouch4me Dust identifies and removes dust specks, scratches, and film artifacts from scanned photographs using convolutional neural networks trained on archival restoration datasets.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Retouch4me Dust** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dust Detection** | Neural network locates dust specks as small as one pixel |
| **Scratch Removal** | Identifies and inpaints linear scratch artifacts across scans |
| **Artifact Grading** | Sensitivity slider controls detection threshold for fine versus coarse dust |
| **Batch Processing** | Process entire directories of scanned images unattended |
